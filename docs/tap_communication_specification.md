# 【システムD：タップ・コミュニケーション（拠点クリック対話）】仕様書・シナリオ設計書

本書は、乙女サスペンスADVゲーム『Two Moons』に導入する、プレイヤー操作型ミニゲーム・システム「タップ・コミュニケーション」の仕様、およびそれを実装するためのプログラムコード、ゲーム内展開シナリオを定義したものである。

---

## 1. システム概要（コンセプト）

### 概要
主人公「朔良（サクラ）」が特定の拠点（例：大学のラウンジ、放課後のたまり場、または秘密の作戦室など）に留まっている際、画面内に配置された4人のキャラクター（睦典、ミカ、凪砂、アキ/大男（アカネ））を任意でクリックし、個別会話を発生させる拠点対話システム。

### 演出方針（日常の裏にある甘さと不穏さ）
* 単調なノベル形式の進行を防ぎ、プレイヤーの主体的な選択によってリアルタイムにキャラクターの好感度が上下する。
* 攻略対象の男たちは全員「裏の顔や異能を隠して日常を装っている」という設定をベースにする。
* プレイヤーがキャラをタップして対話する際、一見すると普通の日常会話だが、クリック時の反応、会話の中身、視線や仕草に「日常の裏にある甘さと不穏さ」が滲み出る演出を施す。
* 会話制限数（例：3回）を設け、限られたアクション数の中で誰を優先して対話するかというゲーム性を持たせる。

---

## 2. ミニゲーム詳細仕様

### ① ゲームフロー
1. **トリガー**: シナリオ進行中、拠点「放課後の特別ロビー」等に移行した際に自動で開始される。
2. **ルール提示**: 画面上部に「Talk Count: 3」などの制限回数インジケーターが表示され、「気になる人物と対話して情報を集め、絆を深めよ」と促される。
3. **ゲームプレイ**:
   * 画面内（横並び、あるいは奥行きのあるサイバーロビー）に、4人の立ち絵（睦典、ミカ、凪砂、アカネ）が美しく配置される。
   * キャラクターの頭上、または足元にはSF調のホログラムネームプレートが表示され、ホバー時にサイバーノイズやグリッチエフェクトが入る。
   * キャラクターをクリックすると、中央のミニダイアログ、またはその場での会話ポップアップが展開され、彼らとの特殊ミニシナリオ（3〜4行程度）が流れる。
   * 会話完了後、該当キャラクターの「好感度（Resonance Ratio）」が上昇し、サイバーハートや波形が明滅するエフェクトが発生する。
4. **結果判定と終了**:
   * トーク回数をすべて消化すると、「対話フェーズ終了」のシステムログが流れ、最も好感度が高かったキャラクター（または最も多く話しかけたキャラクター）に基づいたルート分岐用データ（好感度）を親コンポーネントに返して元のシナリオにシームレスに遷移する。

## 3. キャラクター設定と対話テキスト（日常の裏と甘さ）

### 1. 睦典 (Mutsunori)
* **日常の顔**: 実家の割烹料理を愛する、陽気で少しアホなアットホーム男子。
* **裏の顔・異能**: 【熱量・分子運動の支配】（熱を中和、または極大化させる。料理の火加減や出汁のブレンドに極秘利用しているが、裏では暗殺や戦闘の熱源を凍結・融解する暗部戦闘員）。
* **対話テキスト**:
  ```text
  睦典：「あ、朔良！ちょうど新メニューの試作スープについて考えててさ。
  　　　　……あ、危ないから、この鍋には触っちゃダメだよ？ 
  　　　　今、僕の『手元』は……触れたものすべてを、一瞬で消炭にできるほど熱いから……。
  　　　　……なんてね！ あはは、火傷しちゃうからさ。僕の隣で大人しく待ってて？」
  ```

### 2. ミカ (Mika)
* **日常の顔**: 小悪魔的で、主人公に執着する自称「可愛い後輩」。
* **裏の顔・異能**: 【五感幻覚・神経遮断】（自身の容姿や声、環境の認識を書き換える。甘いおねだりの裏で、ターゲットを精神的に死に至らしめる甘美な暗殺者）。
* **対話テキスト**:
  ```text
  ミカ：「せんぱ〜い！僕に話しかけてくれるなんて、やっぱり運命ですね！
  　　　　ねぇ、先輩の目には、今の僕がどんな風に映ってますか？
  　　　　……僕の本当の姿、本当の『声』がどんなに醜くておぞましくても、
  　　　　先輩だけは、僕のことを見失わないで、優しく抱きしめてくれますよね……？」
  ```

### 3. 凪砂 (Nagisa)
* **日常の顔**: 冷静沈着、成績優秀な生徒会長。
* **裏の顔・異能**: 【時空間計測・絶対予知】（数秒先から数分先の未来、因果の収束線を視認する。だが、その過剰な情報量は脳に激痛を走らせる）。
* **対話テキスト**:
  ```text
  凪砂：「……君か。不意に声をかけられると、視界の因果律が狂う。
  　　　　だが……不思議だな。君の隣にいるときだけは、私の脳を刺す
  　　　　数秒先の不吉な未来の映像が……すべて静かに消え去る。
  　　　　お願いだ、もう少しだけそばに。君の『無能力』で、私の痛みを中和してくれ……」
  ```

### 4. アカネ / 大男 (Akane)
* **日常の顔**: 口数が少なく、いつも物陰から主人公を見守るミステリアスな大柄の護衛役。
* **裏の顔・異能**: 【超重力障壁・空間歪曲】（周囲の弾道や空間を圧縮・偏向させ、あらゆる物理的破壊から対象を守る。常に感情を殺しているが、主人公に対しては異常なまでの独占欲を持つ）。
* **対話テキスト**:
  ```text
  アカネ：「……俺に用か。……怪我はないな？
  　　　　　お前の周囲の重力が、僅かに乱れているのを感じた。
  　　　　　心配するな。お前に近づくすべての悪意、銃弾、人工月の有害な光さえ、
  　　　　　俺のこの手で、空間ごとねじ伏せて、すべて無に還してやる……」
  ```

## 4. プログラムコード設計

Reactで実装する「TapCommunication」コンポーネントは、以下の機能・デザイン要素を盛り込む。
1. **ホログラフィックな拠点マップ風UI**:
   * SF感あふれるグリッド線、レーダー、ステータスインジケーター（Resonance Status）。
2. **インタラクティブな立ち絵配置**:
   * 4人の立ち絵を並べ、ホバーで明るくなり、ホログラム調のノイズが入るインタラクション。
3. **会話ダイアログウィンドウ**:
   * キャラクターをタップした際、そのキャラクターの専用のセリフ、表情、好感度上昇エフェクト（好感度バーのアニメーション）がその場で美しく展開。
4. **好感度リアルタイム反映**:
   * 4人の好感度をステータスバーとして画面隅に表示。
   * トーク回数制限（例：3回）に達すると、最終的な好感度情報（最も高いキャラのデータなど）を親に引き渡し、シナリオを終了・分岐させる。
