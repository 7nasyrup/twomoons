# 【システムA：サーチ＆ラーニング（家・世界観探索）】仕様書・シナリオ設計書

本書は、乙女サスペンスADVゲーム『Two Moons』に導入する、プレイヤー操作型ミニゲームシステム「サーチ＆ラーニング」の仕様、およびそれを実装するためのプログラムコード、ゲーム内展開シナリオを定義したものである。

---

## 1. システム概要（コンセプト）

### 概要
主人公「朔良（サクラ）」の自宅（自室）内にある、情報源となるオブジェクト「テレビ」「新聞」「本棚」をクリックし、人工月や街で発生している異能犯罪、キメラのニュース、歴史といった世界観の深層を調べる探索ゲーム。
プレイヤーが獲得した情報量（調べた数）に応じて、その直後の会話で通常では表示されない「特殊なツッコミ選択肢（ルート分岐用）」が解放され、攻略キャラクターの裏の顔へより深く迫ることができる。

### 演出方針（日常の裏にある甘さと不穏さ）
* 背景には薄暗く差し込む青い人工月の光を描写。
* クリックされたオブジェクトごとにサイバー風のポップアップ画面が表示され、不穏な世界観（「月波エネルギーの毒性」「防衛局が隠蔽するキメラ被害」「父の失踪に関わる古い学術書」など）が明かされる。
* 全てを調査することによって、攻略対象の言葉の矛盾に「鋭くツッコむ」選択肢が出現し、彼が日常の裏に隠している秘密や異能へ切り込むことができる。

## 2. ミニゲーム詳細仕様

### ① ゲームフロー
1. **トリガー**: シナリオ中、自室に帰宅した場面で「探索モード」が発動（`action: 'TRIGGER_SEARCH_AND_LEARNING'`）。
2. **ルール説明**: 「画面内の怪しい場所（テレビ、新聞、本棚）をタップして、世界観の情報を収集しよう！」というメッセージが表示。
3. **ゲームプレイ**: 
   * 朔良の部屋の背景が表示される。
   * インタラクティブなポイントとして「テレビ」「新聞」「本棚」が点滅（またはホバーでハイライト）。
   * それぞれをクリックすると、詳細な調査テキストが表示され、「学ばれた情報（ラーニングポイント）」が蓄積される。
4. **終了判定**:
   * プレイヤーは画面右下の「探索を終了する」ボタンを押すことで、いつでも探索を完了してシナリオへ戻ることができる。
5. **選択肢解放システム**:
   * 直後に発生する選択肢シーンにおいて、ラーニングポイント（調べた数）が最大（3点満点）である場合のみ、特別な「特殊なツッコミ選択肢」がアクティブ（選択可能）になる。情報が足りない場合はロック（半透明・選択不可、または非表示）される。

### ② 探索ターゲット（オブジェクト）
1. **テレビ (TV)**: 「キメラ襲撃ニュース」
   - 昨夜、近隣区画で発生したキメラ被害。公式発表では「ガス爆発」と報道されているが、映像の端に映る不自然なクレーター、そして防衛局が素早く周囲を封鎖したという不審なニュースを学習する。
2. **新聞 (Newspaper)**: 「月波エネルギー50周年特集」
   - 人工月がもたらすクリーンエネルギーの恵みを賞賛する一方で、そのエネルギー「月波（LUNAR WAVE）」が一定値を超えると、人間の精神に狂気（過負荷）をもたらす「月波症候群」の存在について裏面で小さく告発している記事を学習する。
3. **本棚 (Bookshelf)**: 「父の研究ノートのコピー」
   - 失踪した父が遺した「人工月の裏側に真実がある。本物の月の質量は消えたのではなく、時空の裏側へ中和・隔離されたのだ」という、今の月科学では『禁書』に指定されているような仮説を学習する。

## 3. ゲーム展開シナリオ

### 【導入シーン：深夜の自室】
* **背景**: 主人公（朔良）の自室。
* **状況**: 凪砂やミカ、睦典と出会い、様々な事件に翻弄されて自室に逃げ帰った朔良。

```text
朔良
「はぁ……。なんだか、もの凄く長い一日だった気がする……」
「今日出会った凪砂さんも、怪我をしていたミカくんも……みんな何かを隠しているみたいだった」
「それに、お父さんの言っていた『本物の月』のこと……。もう一度、身の回りのものを調べて、情報を整理してみよう」
```
#### ⇒ ここで【サーチ＆ラーニング】ゲーム開始！

---

### 【探索中のラーニングテキスト】

#### ① テレビを調べた
```text
テレビから深夜のニュースキャスターの声が流れている。
『――昨夜発生した〇〇区での大規模な爆発事故について、防衛局は特殊ガス導管の破損によるものと断定しました』

朔良
「ガス爆発……？ でも、画面の端に映ってるあのクレーター、まるで巨大な獣の爪で引き裂かれたような形をしてる」
「防衛局の動きも早すぎる。事故発生から数分で周囲を完全にドーム状の結界で封鎖するなんて、まるで“何か”を外に逃がさないように閉じ込めたみたい……」
（キメラ襲撃ニュースの矛盾について【ラーニングポイント】を獲得！）
```

#### ② 新聞を調べた
```text
テーブルの上に置かれた夕刊。人工月のエネルギー供給50周年を祝う華やかな記事が踊る。
しかし、その紙面の隅、小さな週刊コラムに奇妙な記述を見つけた。
『適応不全――月波（げっぱ）を浴びることで発現する異能力だが、その強すぎる力は脳に過負荷をかけ、やがて自我を崩壊させる。この“月波症候群”の進行は、中和の波長を持つ存在が傍にいなければ、防ぐことはできない――』

朔良
「異能の力を使うと、頭が壊れていっちゃうの……？
　だから、みんなあんなに冷たい瞳をしたり、頭痛に耐えるように苦しんでいたのかな……」
（異能の代償と自我の摩耗について【ラーニングポイント】を獲得！）
```

#### ③ 本棚を調べた
```text
古い本棚の奥。お父さんが昔遺していった、擦り切れた研究論文の写しを引っ張り出す。
『――人工の月は、地球の資源を再生する。しかし、その本質は“真実を隠すための巨大な幻影”だ。本物の月は破壊されたのではない。人工月の生み出す強力な中和フィールドによって、時空の裏側に“無効化・封印”されているのだ』

朔良
「本物の月は、人工月の裏側で眠っているだけ……？
　無効化、フィールド……。もし、私がお父さんから譲り受けたこの“無能力”の体質が、その無効化の鍵を握っているとしたら……？」
（人工月と無効化の真実について【ラーニングポイント】を獲得！）
```

### 【探索終了後のストーリー展開：特殊ツッコミ選択肢の解放】
探索終了後、自室のチャイムが鳴り、攻略キャラクター（例：ミカ、または凪砂）が不意に部屋を訪れる。
そこで彼が語る「ガス爆発」や「日常の体調不良」という嘘に対し、探索で得た十分な情報があれば、鋭く矛盾を突く選択肢が解放される。

#### シーン例：ミカが突然訪ねてくる
```text
チャイムが鳴り、ドアを開けると、そこには包帯を巻いたミカが立っていた。

ミカ
「夜遅くにすみません、先輩。これ、昼間借りてた水を返しに来ました」
「さっき、近くでガス爆発の事故があったみたいで、物騒なんで戸締まりはしっかりした方がいいですよ」

朔良
「ありがとう、ミカくん。でも……」

【通常選択肢】
1. 「うん、戸締まりは気をつけるね」
2. 「ミカくんのその傷、爆発に巻き込まれたの？」

【特殊なツッコミ選択肢】（テレビ・新聞・本棚の3つを全て調べた場合のみ解放）
3. ⇒「ガス爆発なんて嘘だよ。あれは“キメラ”の爪痕だった。ミカくん、あなたその戦いにいたんでしょ？」
```

#### 選択肢3を選択した場合（裏の顔ルート突入）：
```text
ミカ
「……っ！？」
ミカは一瞬だけ、その綺麗な黒い瞳を血のような【赤】に明滅させ、息を呑んだ。
昼間の生意気な後輩としての表情が完全に消え去り、冷酷な『異能適応者』としての鋭いオーラが室内に充満する。

ミカ
「先輩……アンタ、ただの無能力者のくせに、どこまで知ってるんですか？」
「ガス爆発なんて嘘を、防衛局がどれだけ必死に隠蔽してるか……分かってて言ってます？」

ミカは音もなく私の距離を詰め、私の首筋にその細く冷たい指先を滑らせた。
不穏な沈静。けれど、彼の指先からは、なぜか私を傷つけたくないという甘い躊躇いが伝わってくる。

ミカ
「……バカですね。そんな余計なツッコミを入れたら、もう普通の日常には戻れませんよ、先輩」
```
* **効果**: ミカの「裏の顔・異能ルート」が正式に解放され、好感度、サスペンスフラグ「隠蔽された真実」を獲得。
