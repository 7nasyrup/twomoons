# 【システムC：サイレント・スコア（息合わせリズムゲーム）】仕様書・設計書

本書は、乙女サスペンスADVゲーム『Two Moons』に導入する、プレイヤー操作型ミニゲームシステム「サイレント・スコア」の仕様、およびそれを実装するためのプログラムコード、ゲーム内展開を定義したものである。

---

## 1. システム概要（コンセプト）

### 概要
攻略対象の男が「異能の過負荷」や「制御不能な異能の暴走」によって肉体的・精神的な劇痛に悶えている際、主人公「朔良（サクラ）」が自らの持つ「無効化（中和）」の波長を彼に合わせ、シンクロさせることで、その苦痛を和らげてあげるゲーム。

### 演出方針（BGM合わせは不要・タイミングタップゲーム）
* 「BGMに合わせる」必要はなく、視覚的なタイミング（サークルや流れるレーンのターゲット）に合わせてノーツをタップする、シンプルで手触りの良いタップゲームとする。
* タップの判定（Perfect / Great / Good / Miss）によってコンボが繋がり、画面上部の「シンクロ率（中和ゲージ）」が上昇する。
* コンボ数が高いと、朔良の持つ無効化波長が完璧にシンクロし、彼の苦痛が和らぎ、好感度や好意的な演出が発生する。

---

## 2. ミニゲーム詳細仕様

### ① ゲームフロー
1. **トリガー**: シナリオ中に「異能暴走・共鳴イベント」が発生。
2. **ルール説明**: 「タイミングよくノーツをタップし、彼の波長とシンクロ（中和）せよ！」というミッションが表示。
3. **ゲームプレイ**: 
   * **レーン流下式、またはターゲット縮小式**: 本実装では、直感的でスタイリッシュな「流れるノーツをタイミングよくタップするレーン式（あるいはターゲット縮小サークル式）」を採用。
   * タップ成功（Perfect / Great / Good）により、コンボ数が加算。
   * タップ失敗（Miss）により、コンボ数がリセット。
   * 制限時間は20秒。
4. **結果判定**:
   * 最終的なシンクロ率（％）と最大コンボ数が画面に表示される。
   * ゲーム終了後、親コンポーネントにスコア結果を返して、体験用選択肢にシームレスにジャンプ。

### ② ビジュアルデザイン（サイバー×サスペンス）
* 攻略対象の心電図や波形のようなビジュアル、青いノイズ、ネオンカラーのエフェクト。
* 「シンクロ中」のゲージが満ちていく美麗なアニメーション。
