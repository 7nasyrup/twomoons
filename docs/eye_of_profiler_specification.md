# 【システムE：アイ・オブ・プロファイラー（FPS風・視点探索）】仕様書・シナリオ設計書

本書は、乙女サスペンスADVゲーム『Two Moons』に導入する、プレイヤー操作型ミニゲームシステム「アイ・オブ・プロファイラー」の仕様、およびそれを実装するためのプログラムコード、ゲーム内展開シナリオを定義したものである。

---

## 1. システム概要（コンセプト）

### 概要
主人公「朔良（サクラ）」の一人称視点となり、スマートフォンの暗視スキャナーや、暗闇の中でカメラ（ライト）を動かし、周囲に潜む「不審な人影」や「監視の目（ドローン/カメラ）」を制限時間内にエイム（クリック）して暴くFPS風の視点探索ミニゲーム。

### 演出方針（日常の裏にある甘さと不穏さ）
* プレイヤーが素早く（制限時間内に）ターゲットを捉えてプロファイリングを「成功」させるかによって、彼らの真の裏の顔（隠密行動中、または秘密裏のミッション中の冷徹な一面）を暴く特別なイベントが解放される。
* 直接的な異能の全ネタバレは避けつつも、暗闇の中での彼の冷酷な戦闘姿勢、使用している武器、または彼自身の視線が主人公を密かに守護しているような甘さとサスペンスに満ちた描写を徹底する。

---

## 2. ミニゲーム詳細仕様

### ① ゲームフロー
1. **トリガー**: シナリオ進行中、夜のキャンパスや暗い廃工場で「尾行・監視されている気配」を検知した際に開始。
2. **ルール提示**: 画面が「暗視サーマルスコープ（ナイトビジョン）」風の緑色/青色フィルターに切り替わり、「制限時間内（30秒）に暗闇に潜む4つの不審なシグナル（人影・監視カメラ）をエイムしてスキャン（クリック）せよ！」と提示される。
3. **ゲームプレイ**:
   * 画面内にノイズ、スキャンライン、レティクル（照準）が表示される。
   * 画面内のあちこちから、ランダムまたは指定されたポイントに、怪しい赤外線人影や監視センサー（ホログラムグリッチエフェクト付き）が一時的に出現・明滅する。
   * プレイヤーはマウスカーソルやタップで照準を合わせ、素早くクリックしてスキャンを完了する。
   * エイムに成功すると「TARGET LOCKED & SCANNED」というサイバーなエフェクトが走り、プロファイリング率（％）が上昇。
4. **結果判定**:
   * **成功（熟練度：高 / 100%スキャン）**: 制限時間内にすべてのターゲット（監視センサーや怪しい人影）の特定・スキャンに成功。彼らの隠密ミッション中の姿を詳細に記録し、裏ルートが解放。
   * **失敗（熟練度：低 / 未完了）**: 制限時間内にスキャンが間に合わず、ターゲットを見失う。何者かの視線に怯えながら逃げ帰るノーマル・不穏ルートへ。

## 3. ゲーム展開シナリオ（成功・失敗ルート）

### 【共通導入シーン：深夜のキャンパス裏】
* **背景**: 夜の大学構内（不気味な青い月光、激しい機械ノイズ）
* **状況**: 朔良が一人で歩いていると、何者かの「視線」と、上空でかすかに作動する電子音が聞こえる。

```text
朔良
「……誰？ 誰かがそこにいるの……？」

朔良
「（気のせいじゃない。暗闇の奥、それから上空の並木の間から、冷たい機械的なレンズの目が私を狙っている……）」
「スマートフォンの広帯域波長スキャナーを使って、この暗闇をプロファイリングしてみよう！」
```

#### ⇒ ここで【アイ・オブ・プロファイラー】ミニゲーム開始！

## 4. プログラムコード設計

Reactで実装する視点探索コンポーネントは、FPS・暗視スコープの緊迫感を演出するため、以下の要素を盛り込む。
1. **ナイトビジョン / サーマル風ビジュアル**:
   - 緑または青を基調とした暗視ゴーグル風UI、走査線、円形レンズ枠、ノイズグリッチ。
2. **インタラクティブなエイム（クリック）システム**:
   - 画面の四隅や中央付近にランダムに浮上する4つのターゲット（睦典、ミカ、凪砂、ドローン）。
   - マウスポインターが照準（レティクル）になり、ターゲットを捉えてクリックするとスキャンのアニメーションが実行。
3. **制限時間タイマーとゲージ**:
   - 制限時間30秒。ターゲットを倒すごとに、スキャン進捗が 25% ずつアップし、100%でクリア。
4. **終了コールバック**:
   - 成功か失敗の結果を親に返し、シナリオを分岐。
